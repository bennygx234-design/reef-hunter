# Reef Hunter

A first-person 3D spearfishing game that runs in the browser. Three reefs, three guns, points by catch weight.

- Built with Three.js (loaded from a CDN, no build step).
- Static site: open `index.html` through any web server, or deploy the folder to Vercel.
- Controls: mouse aim, click to shoot, WASD swim, Space up, C down, Shift sprint, Esc pause.
